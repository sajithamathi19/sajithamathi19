### 🛠️ Projects

**[reddit-agent](https://github.com/sajithamathi19/reddit-agent)** — AI-driven Reddit marketing agent. An 8-stage pipeline discovers subreddits, drafts posts/comments grounded in each community's real rules, and runs every draft through a multi-agent trust review (a 3-persona Community Simulation, reputation-tiered posting policy, pre-send Timing Advisor) before scheduling it through Reddit's official OAuth API. FastAPI + PostgreSQL + SQLAlchemy + APScheduler.

**[gramagent](https://github.com/sajithamathi19/gramagent)** — Instagram creator-outreach agent. A 5-stage pipeline turns a product description into personalized creator DMs (ICP → Discovery → Resolver → Qualification → Message Generation) and sends them on a schedule through a backend-owned scheduler that survives the frontend closing. FastAPI + Streamlit + Claude API.

**[wealthpilot](https://github.com/sajithamathi19/wealthpilot)** — AI financial agent that connects to real bank accounts via Plaid and reasons over live transactions/balances through a perception → memory → planning → reasoning agent loop, not a static dashboard.

**[voice-prescription](https://github.com/sajithamathi19/voice-prescription)** — Voice-to-prescription healthcare app. Transcribes doctor speech into structured medical fields via a Groq Llama 3 model, with JWT/RBAC-secured REST APIs. React + Node.js + Spring Boot + PostgreSQL.

**[On-Device-GenAI-Retail-Analytics](https://github.com/sajithamathi19/On-Device-GenAI-Retail-Analytics-Offline-RAG-Pipeline-over-Hybrid-OLTP-DW-Architecture)** — Offline RAG pipeline over a hybrid OLTP/data-warehouse architecture, running fully on-device via local Ollama models — no external API calls.
